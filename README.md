# 🧡 ฟอร์มสั่งเสื้อกีฬา SMTE — *be by your side*

ระบบฟอร์มยืนยันการสั่งเสื้อกีฬา SMTE (เสื้อส้มหมายเลข 10) ประกอบด้วย

| ไฟล์ | ทำหน้าที่ |
|---|---|
| `index.html` | หน้าฟอร์มสำหรับให้เพื่อน ๆ กรอกสั่งเสื้อ (ธีมสีส้มตามเสื้อจริง) |
| `apps-script/Code.gs` | โค้ดฝั่งเซิร์ฟเวอร์ (Google Apps Script) บันทึกลงชีท + เก็บสลิปใน Drive |
| `assets/shirt.png` | รูปเสื้อด้านหน้า–หลัง |
| `assets/qr-promptpay.jpg` | QR PromptPay สำหรับรับโอน |

## ความสามารถ

- กรอก **คำนำหน้า / ชื่อ / นามสกุล / ชั้น / เลขที่ / เบอร์โทรศัพท์ / ไซส์ / จำนวน**
- แสดง QR PromptPay ให้สแกนจ่าย แล้ว **อัปโหลดสลิป** ก่อนกดยืนยัน (ระบบย่อรูปให้อัตโนมัติ)
- ข้อมูลถูกบันทึกลง **Google Sheets** และรูปสลิปถูกเก็บใน **Google Drive** พร้อมลิงก์ในชีท
- **ป้องกันการส่งซ้ำ 4 ชั้น**
  1. ปุ่มยืนยันล็อกทันทีระหว่างส่ง (กันกดรัว)
  2. เครื่องที่ส่งสำเร็จแล้วจะถูกจำไว้ (localStorage) เปิดฟอร์มใหม่ก็ส่งซ้ำไม่ได้
  3. ฝั่งเซิร์ฟเวอร์เช็ก `submissionId` เดิม (กันเน็ตหลุดแล้วส่งซ้ำ)
  4. ฝั่งเซิร์ฟเวอร์เช็ก **ชั้น+เลขที่** หรือ **เบอร์โทร** เดิมที่เคยสั่งแล้ว + ใช้ LockService กันกดพร้อมกัน

## 🚀 วิธีติดตั้ง (ประมาณ 10 นาที)

### ขั้นที่ 1 — สร้าง Google Sheet + Apps Script

1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น `คำสั่งซื้อเสื้อ SMTE`
2. ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจากไฟล์ [`apps-script/Code.gs`](apps-script/Code.gs)
4. กดบันทึก แล้วเลือกฟังก์ชัน **`setup`** จากเมนูด้านบน กด **เรียกใช้ (Run)** 1 ครั้ง
   - Google จะขอสิทธิ์เข้าถึงชีทและไดรฟ์ → กด **อนุญาต (Allow)**
   - ขั้นนี้จะสร้างหัวตารางในชีท และสร้างโฟลเดอร์ `SMTE Shirt - สลิปโอนเงิน` ใน Drive ให้อัตโนมัติ

### ขั้นที่ 2 — Deploy เป็น Web App

1. ใน Apps Script กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. ประเภท: **เว็บแอป (Web app)**
3. ตั้งค่า:
   - **Execute as (เรียกใช้ในฐานะ)**: `ฉัน (Me)`
   - **Who has access (ผู้ที่มีสิทธิ์เข้าถึง)**: `ทุกคน (Anyone)`
4. กด Deploy แล้ว **คัดลอก URL เว็บแอป** (ลงท้ายด้วย `/exec`)

### ขั้นที่ 3 — ใส่ URL ลงในฟอร์ม

เปิดไฟล์ `index.html` หาบรรทัดนี้ (อยู่ช่วงต้นของ `<script>`):

```js
const SCRIPT_URL = 'YOUR_APPS_SCRIPT_WEB_APP_URL';
```

แทนที่ด้วย URL ที่คัดลอกมา เช่น

```js
const SCRIPT_URL = 'https://script.google.com/macros/s/AKfycb.../exec';
```

### ขั้นที่ 4 — (ถ้าต้องการ) ใส่ราคาเสื้อ

```js
const PRICE_PER_SHIRT = 0;   // ใส่ราคาต่อตัว เช่น 250 → ฟอร์มจะโชว์ยอดรวมให้อัตโนมัติ
```

ถ้าปล่อยเป็น `0` ฟอร์มจะไม่แสดงยอดรวม (ผู้สั่งโอนตามที่ประกาศไว้)

### ขั้นที่ 5 — เปิดใช้งานฟอร์ม

อัปโหลดทั้งโฟลเดอร์ขึ้นโฮสต์ใดก็ได้ที่เสิร์ฟไฟล์ HTML เช่น **GitHub Pages**:

1. ไปที่ repo → **Settings → Pages**
2. Source: `Deploy from a branch` → เลือก branch หลัก / root
3. รอสักครู่ แล้วแชร์ลิงก์ `https://<username>.github.io/Forms/` ให้เพื่อน ๆ ได้เลย

## 🛠 ปรับแต่งเพิ่มเติม

- **ไซส์เสื้อ / รอบอก**: แก้ในบล็อก `id="sizeGroup"` ของ `index.html`
- **จำนวนสูงสุดต่อคำสั่งซื้อ**: ตัวแปร `MAX_QTY` ใน `index.html` (ค่าเริ่มต้น 10)
- **ปิดการกันซ้ำรายบุคคล** (เช่น อยากให้คนเดิมสั่งได้หลายรอบ): ใน `Code.gs` ตั้ง
  `BLOCK_DUPLICATE_PERSON: false`
- **ชื่อชีท / ชื่อโฟลเดอร์สลิป**: แก้ใน `CONFIG` ของ `Code.gs`
